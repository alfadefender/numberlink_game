Правила головоломки Numberlink:
1) Нельзя допускать, чтобы линии пересекались
2) Полностью поле покрывать необязательно
3) Нет Т-образных путей
4) Все пары чисел должны быть соединены одной линией

Правила ввода головоломки:
1) Поле всегда NxN клеток
2) Клетка с числом заменяется этим числом, пустая клетка заменяется нулем
3) Числа должны идти по возрастанию от 1 до конечного числа,
   каждое на единицу больше предыдущего
4) Головоломка задается как матрица, перед головоломкой в двух строках идут
    два числа - N (размер поля) и M (конечное число содержащееся в головоломке)

Вводить головоломку можно с помощью консоли, либо файла.
Файл по умолчанию для ввода - <input.txt> в папке с файлом main.py,
если файл для ввода указан неверно или не существует - пробросится ошибка.

Головоломка может выглядеть таким образом:
N
M
1 0 0 0 ...
0 3 5 1 ...
...........
2 0 0 3 ...

Примеры ввода головоломки можно посмотреть в папке <examples>

Решение может выводиться в консоль, в файл или в качестве картинки.
Картинки сохраняются в папке <images>.
Файл по умолчанию для вывода <output.txt> создается в той же папке, что и main.

Как пользоваться программой и какие есть аргументы можно посмотреть командой:
<python main.py --help> или <python main.py -h>
