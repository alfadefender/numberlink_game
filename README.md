<h2>Правила головоломки Numberlink:</h2>

1) Нельзя допускать, чтобы линии пересекались
2) Полностью поле покрывать необязательно
3) Нет Т-образных путей
4) Все пары чисел должны быть соединены одной линией

<h2>Правила ввода головоломки:</h2>

1) Поле всегда <b><i>N</i></b>x<b><i>N</i></b> клеток
2) Клетка с числом заменяется этим числом, пустая клетка заменяется нулем
3) Числа должны идти по возрастанию от 1 до конечного числа,
   каждое на единицу больше предыдущего
4) Головоломка задается как матрица, перед головоломкой в двух строках идут
    два числа - <b><i>N</i></b> (размер поля) и <b><i>M</i></b> (конечное число содержащееся в головоломке)
<br>
<h3>Вводить головоломку можно с помощью консоли, либо файла.</h3>

Файл по умолчанию для ввода - <b>input.txt</b> в папке с файлом <i>main.py</i>,
если файл для ввода указан неверно или не существует - пробросится ошибка.


<h3>Головоломка может выглядеть таким образом:</h3>
<pre>
N
M
1 0 0 0 ...
0 3 5 1 ...
...........
2 0 0 3 ...
</pre>

<h3>Примеры ввода головоломки можно посмотреть в папке <b>examples</b><br></h3>
