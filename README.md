Правила создания головоломки Numberlink:
1) поле может быть 6, 8 или 10 клеток в длину и ширину (simple, normal, advanced)
2) чисел на поле всегда N штук (для поля NxN)
3) всегда есть хотя бы одно решение головоломки
4) нельзя допускать, чтобы линии пересекались
5) полностью поле покрывать необязательно
